# CAGE Step Book

All 98 questions from the Computer Aided Engineering Graphics (CAGE) module — points, lines, planes, solids, development and isometric — drawn one step at a time.

Open the app: https://tejass0027.github.io/caed/

Install it:
- Android (Chrome): menu ⋮ → Install app
- iPhone (Safari): Share → Add to Home Screen
- Windows (Edge or Chrome): install icon in the address bar, or menu → Apps → Install this site as an app

Works offline after the first visit.
